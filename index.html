네이버 블로그 게시 준비

내 블로그 · blog.naver.com/thkim5579

MP4 등 동영상 파일을 선택하세요
영상 파일명에 맞는 게시 내용을 자동으로 준비합니다. 내용은 직접 수정할 수 있습니다.
동영상 첨부 방법
이 퍼블리셔에서는 선택한 동영상을 확인하고 게시용 제목·본문·해시태그를 준비합니다.
1. 영상 선택 → 2. 제목·본문 자동 생성 확인 → 3. ⑤ 버튼으로 제목·본문 복사 → 4. 네이버 글쓰기에서 동영상을 직접 첨부 → 5. 전체 공개 → 발행
게시 체크
사용 순서
① 동영상 선택 → 파일명에 맞는 제목·본문·해시태그 자동 준비 → ⑤ 제목·본문 복사 + 네이버 글쓰기 열기 → 네이버 글쓰기에서 동영상을 직접 첨부 → 복사한 제목·본문·해시태그를 붙여넣기 → 전체 공개 → 발행.

이 퍼블리셔는 게시 준비를 담당하고, 실제 동영상 첨부는 네이버 글쓰기에서 사용자가 직접 합니다.
